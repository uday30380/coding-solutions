## Problem

### Task - My Image Showcase

 **Goal:**  Create a webpage that displays three different images from the web - a bustling city, a mountain range, and a forest - each with a description and specific dimensions.

 **Instructions:** 

- Add a main heading (<h1>) with the same text.
- Insert three images with these requirements: First image: Must come from a free, publicly accessible source. Represents a bustling city. Displayed at 500px width and 300px height. Second image: Must come from a different free public source. Represents a mountain range. Displayed at 400px width, height is not fixed. Third image: Also from a free public source. Represents a forest. Displayed at 600px width and 400px height.
- Provide descriptive alt text for all images.
