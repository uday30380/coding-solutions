## Problem

### My Favorite Movie Page - Project 2
- You need to create a Movie Webpage using HTML that showcases your favorite movie.
- This project will help you practice anchor tags, images, video, audio, and iframe embedding.

 **Requirements** 

- Movie Title & Description Add a <h1> with the movie title. Write a short description inside a <p>.
- Links (Anchor Tags) Add a link to the official movie website using an absolute URL, and make it open in a new tab (target="_blank"). Add a relative link to another page in your project folder (e.g., about.html). Add an anchor link that jumps to the Cast Section on the same page (#cast).
- Image Display a movie poster using <img>. Use alt text to describe the image. Add either width or height attribute. Use loading="lazy" for performance.
- Video Embed a local video file (trailer.mp4) using <video controls>.
- Audio Embed an audio file (theme.mp3) using <audio controls>.
- YouTube Video Embed a YouTube trailer using <iframe>.
- Cast Section Create a <h2> with id="cast". Add a list of at least 4 actors using an unordered list (<ul> + <li>).
