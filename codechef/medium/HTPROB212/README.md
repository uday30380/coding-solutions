## Problem

### Task - Add div Wrappers to a Simple News Page

 **Goal:**  Learn how to use `<div>` as a wrapper while combining it with semantic elements like `<header>`, `<main>`, and `<footer>`.

 **Instructions** 

- You are given a simple HTML structure for a news page.
- The content for header, main articles, and footer is already provided.
- Your task is to add <div> tags to group sections and articles:
- Wrap the entire page content inside a main <div>.
- Inside <main>, wrap each article inside its own <div>.
- Ensure the <div> elements do not break the content and stay inline with semantic sections.
- You can keep all headings (<h1>, <h2>), paragraphs (<p>), and links (<a>) as they are — only add <div> wrappers where necessary.
