## Problem

### Task - Add section Tags to Your webpage

 **Goal:**  Practice using the `<section>` tag to organize content inside `<main>`, while keeping the header and footer unchanged.

 **Instructions** 

- You are given a personal webpage with a header, main content, and footer.
- Inside <main>, there are three content blocks:
- About Me (heading + two paragraphs)
- My Hobbies (heading + list of hobbies)
- Contact (heading + paragraph with email)
- Your task is to wrap each content block inside a <section> tag:
- Section 1: Wrap the "About Me" heading and paragraphs inside <section>.
- Section 2: Wrap the "My Hobbies" heading and list inside <section>.
- Section 3: Wrap the "Contact" heading and paragraph inside <section>.
- Make sure:
- <section> elements are only used for grouping each content block.
- Do not include header or footer inside <section>.
- All headings, paragraphs, and list items remain unchanged.
