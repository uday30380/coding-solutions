### Task - Add footer Tags

 **Goal:**  Use `<footer>` tags for both  **article-specific**  and  **site-wide**  content.

 **Instructions** 

- Inside <main>, after the paragraph, add a <footer> for the blog post: Include the author's name (e.g., "Posted by Jane Doe") Include the publication date (e.g., "Published on October 26, 2023")
- After </main>, add a site footer: Include a copyright notice using &copy; (e.g., "© 2024 My Awesome Blog") Add a <ul> with links: "Privacy Policy" and "Contact Us"
