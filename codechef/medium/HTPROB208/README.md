## Problem

### Task - Add article to a Blog Post Page

 **Goal:**  Practice using the `<article>` tag to represent a blog post while keeping the page structure with `<header>`, `<main>`, and `<footer>`.

 **Instructions** 

- You are given a simple blog page with a header, main content, and footer.
- Inside the <main> element, there is blog content but it is not wrapped in an <article> tag yet.
- Your task is to:
- Wrap the blog post content (heading, paragraphs, author/date) inside an <article> tag.
- Make sure the <article> element only contains the blog post content and does not include header or footer.
- All headings (<h2>), paragraphs (<p>), and other content remain unchanged — you are just adding the <article> wrapper.

      <p>Learning web development is an exciting experience. It starts with small steps, such as understanding HTML, which forms the backbone of any webpage. As learners progress, they explore CSS for styling and JavaScript for interactivity. With practice, building complete websites becomes achievable and rewarding.</p>
      
      <p><strong>Written by:</strong> Alex | <em>January 15, 2025</em></p>
    
  </main>
